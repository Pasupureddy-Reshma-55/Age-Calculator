# 🎂 Age Calculator

## 📌 About the Project

The **Age Calculator** is a simple and user-friendly web application that calculates a person's exact age based on their date of birth. It displays the age in years, months, and days.

This project helps users calculate their age quickly and accurately with a simple and attractive user interface.

## ✨ Features

- Calculate exact age.
- Display age in years, months, and days.
- Simple and user-friendly interface.
- Responsive design.
- Easy date selection.
- Instant age calculation.

## 🛠️ Technologies Used

- HTML5
- CSS
- JavaScript
